# Harness API

`RailToolKit` is a thin re-export layer. Domain logic lives in upstream packages
listed by active use cases.

```@autodocs
Modules = [RailToolKit]
```

For running-time calculation APIs, see the upstream
[TrainRuns.jl docs](https://www.railtoolkit.org/TrainRuns.jl/dev/).
Catalogue package landings appear under [Packages](generated/packages.md) only when
an **active** use case lists them.

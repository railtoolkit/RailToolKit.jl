Harness API

RailToolKit is a thin re-export layer. Domain logic lives in upstream packages listed by active use cases.

RailToolKit.RailToolKit — Module
RailToolKit

Thin integration harness for RailToolKit use cases.

This package does not own domain types or algorithms. It re-exports the public APIs needed by active use cases under usecases/ so tutorial-style scripts can using RailToolKit. Calculation ownership stays upstream (TrainRuns.jl for UC-001).

source

For running-time calculation APIs, see the upstream TrainRuns.jl docs. Catalogue package landings appear under Packages only when an active use case lists them.
